# Orgo 101 — checked GitHub Pages files

Checked 15 October 2026.

## Upload

1. Extract the ZIP first.
2. Upload the files **inside** the extracted folder to your existing GitHub Pages publishing folder, replacing matching files. Keep `index.html` at the top of that folder.
3. Commit the changes and allow GitHub Pages to deploy.

No installation or build command is required. `CNAME` keeps your existing `curlyarrowpractice.com` domain. `.nojekyll` keeps the site as plain static files.

The question illustrations are embedded in `thermodynamics-bank.js` to keep the upload below GitHub's 100-file limit. The illustrations and question data were checked against the original files.

## Included

All approved sections from the demo, including SN2, E2 and **Reorient and React**. Product drawing asks for the main product; counterions and other by-products appear after a correct answer.

The abandoned full-reaction draft is excluded. If these old draft files are still in your repository, delete them: `substitution.html`, `substitution.css`, `substitution-bank.js`, `substitution-geometry.js`, `substitution.js`. Uploading a new ZIP does not remove old files automatically. The current approved Substitution and Elimination pages have different filenames and are included.

## Verification

Chemistry and answer marking, question counts, hints, previous/next controls, drawing tools, stereochemistry, arrows, product spacing, local links and asset references were checked with the automated suites. Naming and Newman projection questions received additional independent graph and answer checks. Representative updated drawings were rendered and visually inspected.

Live browser testing was unavailable during this audit. Please open the deployed site once after GitHub finishes publishing, including on your phone, before distributing it to students.
