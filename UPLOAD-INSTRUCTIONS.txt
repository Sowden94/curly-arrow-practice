Orgo 101 - Compact GitHub Update - 7 October 2026

1. Extract this ZIP.
2. Open your curly-arrow-practice repository on GitHub and choose Add file > Upload files.
3. Upload ALL the extracted website files together into your existing GitHub Pages source folder, replacing matching names. Do not upload the ZIP or an enclosing folder.
4. Commit the upload and wait for GitHub Pages to deploy. Keep your existing Pages settings.
5. If the old site appears, hard-refresh: Mac Command + Shift + R; Windows Ctrl + Shift + R.
